# 🌍 World Happiness EDA with Python

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the World Happiness Report dataset for 2020 and 2021. The goal is to understand the factors affecting happiness across different countries and regions.

---

## 🎯 Objectives
- Analyze happiness scores across countries
- Compare 2020 vs 2021 data
- Identify key factors affecting happiness
- Visualize trends using graphs

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Dataset
- World Happiness Report (2020 & 2021)
- Includes features like:
  - GDP per capita
  - Social support
  - Life expectancy
  - Freedom
  - Generosity
  - Corruption perception

---

## 🔍 Key Analysis Performed
- Data cleaning and handling missing values
- Statistical analysis using `.describe()` and `.info()`
- Visualization using:
  - Box plots
  - Scatter plots
  - Histograms
  - Violin plots
- Country-wise comparison between 2020 and 2021

---

## 📈 Key Insights
- Most countries have happiness scores between **4 and 7**
- Western Europe shows highest happiness levels
- Strong positive correlation between:
  - GDP per capita
  - Social support
  - Life expectancy
  - Freedom of choice
- Economic and social factors significantly impact happiness
